# CS4973-Applied-Multilingual-Systems

## Course Description
This hands-on, project-based course dives deep into the exciting intersection of Artificial Intelligence, Large Language Models (LLMs), and multilingual NLP. Designed for rising juniors with a strong background in object-oriented design and programming (e.g., CS 3500 OOD), students will engage in building a complete system for code-switching prediction. Working in teams of up to four, each group will select a unique bilingual language pair (e.g., English-German, English-Spanish, English-Hindi), then design and implement a robust methodology for generating high-quality, synthetic code-switched conversational datasets using LLMs and tools like Microsoft Copilot Studio.
The initial phase of the course focuses on advanced prompt engineering and data generation techniques, aiming to complete dataset creation by mid-semester. The latter half pivots to model implementation and evaluation. Students will apply their coding skills to build, train, and evaluate machine learning or deep learning models capable of predicting code-switching events within their generated data. This involves significant coding, data analysis, visualization, and critical assessment of model performance and the linguistic characteristics of code-switching. The course will also explore the theoretical underpinnings of agentic AI and LLM frameworks, integrating these concepts into practical application. Ethical considerations in synthetic data generation and AI model deployment will be a continuous theme. This course culminates in a comprehensive final project demonstrating a complete AI system, from data generation to model evaluation and insightful analysis.

## Learning Objectives
Upon successful completion of this course, students will be able to:
•	Design and implement sophisticated prompt engineering strategies for generating complex, linguistically nuanced synthetic datasets, specifically bilingual code-switched conversations.
•	Programmatically interact with advanced AI models (LLMs via APIs and potentially Microsoft Copilot Studio) to execute large-scale data generation.
•	Apply computational linguistic techniques to analyze and characterize the code-switching phenomena within generated datasets.
•	Design, implement, train, and evaluate machine learning or deep learning models for code-switching prediction using their generated datasets.
•	Utilize appropriate metrics and visualization tools to rigorously assess model performance and interpret results.
•	Understand and apply foundational concepts of Agentic AI, including model architecture, underlying frameworks, and the principles of intelligent agents.
•	Critically analyze and address ethical considerations related to synthetic data generation, AI bias, and the responsible deployment of multilingual AI systems.
•	Collaborate effectively in a team on a complex, full-stack AI project, including version control, task management, and technical communication.
•	Present their methodologies, findings, and complete system architecture clearly and professionally to a technical audience.
Prerequisites
Completion of 4 semesters of a Computer Science curriculum, including CS 3500 (Object-Oriented Design) or an equivalent course demonstrating strong programming and software design skills. Familiarity with Python is essential.

## Course Materials
•	Primary Tool: Microsoft Copilot Studio (provided via course subscription for faculty and students).
•	Core Development Environment: Google Colab (free, web-based, for Python scripting, data processing, and model training). Local Python environment with Jupyter Notebooks/VS Code is also highly encouraged for robust development.
•	Key Python Libraries: pandas, numpy, scikit-learn, tensorflow/pytorch (for deep learning models), transformers (Hugging Face), matplotlib, seaborn.
•	AI Access: Access to relevant LLM APIs (e.g., Google Gemini, OpenAI's ChatGPT APIs – we'll use free/educational tiers and carefully manage usage).
•	Recommended Readings/Resources:
o	Selected chapters/sections from "Speech and Language Processing" by Jurafsky & Martin (for NLP foundations, available online).
o	Articles and documentation from OpenAI, Google AI, Hugging Face on LLMs, prompt engineering, and specific model architectures.
o	Research papers on code-switching detection, synthetic data generation, and Agentic AI.
o	(As suggested by faculty) Materials from Ryan Rad's LLM course (Vancouver), focusing on Agentic AI frameworks and practical LLM applications.
